# Fetzi's Displays: Issue Tracker

This repository is only for **bug reports, crash reports and suggestions** for
[Fetzi's Displays](https://modrinth.com/mod/fetzis-displays).

## Report something

👉 **[Open a new issue](../../issues/new/choose)** and pick a form:

| Form | Use it for |
|---|---|
| 🐛 Bug report | Something doesn't work the way it should |
| 💥 Crash report | The game crashes or doesn't start |
| 💡 Suggestion | Ideas for new displays, features or changes |

Before you report, please [search the existing issues](../../issues?q=is%3Aissue). Maybe it's already known.

**Logs:** upload `logs/latest.log` or the crash report from `crash-reports/` to
[mclo.gs](https://mclo.gs) and paste the link into the form.
